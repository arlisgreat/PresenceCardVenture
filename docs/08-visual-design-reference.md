## 视觉语言

### 色彩

核心色板来自“淡彩版”参考：

| 名称 | 色值 | 用法 |
|------|------|------|
| 纸白 | `#fbf9f7` | 页面底色、留白 |
| 淡粉 | `#f6dfe4` / `#d98ba0` | 主强调、轻回应、选择态 |
| 雾蓝 | `#dce8f2` / `#7fa3c4` | CCD、设备、链接 |
| 鼠尾草绿 | `#a8bfa0` / `#5f7a58` | 模板、已完成状态 |
| 墨灰 | `#3a3f45` | 正文与标题 |
| 发丝线 | `#e9e2dd` | 分隔线、边框 |

页面以纸白为底，颜色只承担信息分组，不使用高饱和渐变或喧闹的社交媒体红点。

### 字体与排版

- 标题使用有性格的中文衬线体（优先 `Noto Serif SC`，本地不可用时回退系统衬线体）。
- 正文和控件使用轻量无衬线体（优先 `Noto Sans SC`）。
- 标题留白充分，正文行高约 1.8–2.0；工具数据使用小字号和较宽字距。
- 采用单列大图、轻边框、少阴影；卡片圆角保持克制（约 4–8px）。

## 产品结构映射

参考文档把软件世界分成三个“房间”，应用实现保留这个结构：

1. **圈子**：小圈好友流、大圈分圈和安静的内容浏览。
2. **我的足迹**：按日期归档自己释放的照片与一句话。
3. **玩法库**：轻美颜、CCD 滤镜、素材模板三类入口，选择后可下发到设备。

AI 合照作为独立的创作入口，设备实验室作为开发/联调入口，不与普通社交流混在一起。

## 交互原则

- 互动以小星星、拍一拍、一句话和语音贴为主；第一版不做公开评论区和喧闹红点。
- 三类拍摄玩法必须在 UI 上明确分组：轻美颜、CCD 滤镜、素材模板，不能退化成一排无语义的滤镜按钮。
- 上传、处理、AI 生成和设备下发都显示明确的进行中、成功和失败状态。
- 内容可见范围和授权状态在发布前可见，删除动作可撤销或明确反馈。
- 保持移动优先，同时让桌面端适合路演和调试。

## Demo 内容与生产边界

本地 Demo 可以使用种子内容和可控的模拟 AI 结果，但接口、权限、任务状态、删除和设备协议按生产形态实现。真实 Gemini/ASR/OSS、域名 HTTPS 和硬件设备需要在部署环境注入配置，不能把密钥或临时素材提交到仓库。
