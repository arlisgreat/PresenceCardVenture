# 联调验收

| 顺序 | 验收结果 | 对接 |
|------|----------|------|
| 1 | 小卡拍照 → Web 可见 → Web 下发 → 小卡显示并回执 | 全栈 ↔ 硬件 |
| 2 | 用户扫码加入 → 加好友 → 收发文字/图片 | 全栈 ↔ 吉吉 |
| 3 | 双方授权素材 → AI 合照 → 会话可见 → 主人确认发布到社区/发到小卡 | 算法 ↔ 全栈；吉吉验效果，xana 确认路演功能 |

## 提交要求

- Issue 写负责人、接收方、验收条件。
- 角色分支同步 `main` 后提交 PR；附交付路径、运行步骤、测试证据和已知限制。
- 接口变更先合契约 PR，再改实现；接收方验收后合并 `main`。
- 硬件日志：`[FW] METHOD PATH STATUS MS`；附固件版本和复现步骤。
- 密钥及真实用户数据不提交 Git；测试素材须获授权。
