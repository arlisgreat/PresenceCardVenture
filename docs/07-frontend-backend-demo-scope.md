# 完整社区应用与 Demo 交付范围

## 目标

在不依赖真实硬件的前提下，交付一个可以真实操作的社区应用版本，覆盖“用户上传照片 → 云端处理 → 圈子展示与互动 → 可选生成合照 → 设备模拟联动”的端到端体验。真实硬件和第三方服务通过适配层接入，不阻塞应用交付。

## 第一阶段范围

### P0：必须可演示

- Web 用户身份：注册/登录或可替代的 Demo 用户身份。
- 图片上传：上传图片、保留原图元数据，并展示处理状态。
- 基础处理：至少支持一组 CCD/暖色等风格和基础美颜参数（匀肤、美白、清晰、大眼可先做可控的 Demo 效果）。
- 社区时间线：展示自己和已授权好友的图片，包含作者、时间、滤镜信息和图片预览。
- 互动：图片点赞，以及文字/图片消息的最小闭环。
- 删除：用户可以删除自己的原图、处理结果和 AI 合照结果。

### P1：完整应用必须可走通

- 贴纸或拍立得风格边框素材，先提供 1–2 个可用样式。
- AI 合照异步任务：创建任务、显示排队/处理中/成功/失败状态；Demo 阶段可使用模拟生成器。
- 设备模拟面板：模拟设备上传一张照片、拉取好友动态、接收下发并回传回执。
- 小圈、大圈和分圈筛选；默认采用授权可见，未授权内容不可进入时间线。
- 我的足迹：按日期查看自己发布过的照片与处理结果。
- 玩法库：轻美颜、CCD 滤镜、素材模板三类入口，选中配置后可标记为设备下发配置。
- 语音贴/一句话先提供文字状态和音频占位，真实 ASR 通过服务端适配器接入。

## 生产前置条件与明确限制

- 真实 M5Stack/CoreS3 硬件联调、拍照、刷屏和低功耗实现。
- 生产环境的 OSS、域名、HTTPS、限流、备份和压测需要部署环境凭据；代码和配置模板会准备好，但本地无法替代真实云资源。
- TikTok/抖音等第三方特效资源的正式接入，除非完成授权和资源确认。
- 语音、卡间离线互动以及离线好友票等协议中的预留能力。

## 验收标准

1. 用户可以在 Web 端完成一次图片上传，并看到原图和处理结果的关联关系。
2. 已授权好友可以在时间线看到图片；未授权用户看不到受限内容。
3. 用户可以对图片点赞、发送文字或图片消息，并删除自己拥有的内容。
4. 创建 AI 合照后，页面能展示任务状态；成功和失败都有明确反馈。
5. 设备模拟面板能完成上传、拉取和回执流程，且不改变设备 API 的字段语义。
6. API 和 Web 均能在本地按仓库 README 的方式启动，关键流程有可重复的测试或请求样例。

## 建议实现顺序

1. 先补齐 API 的健康检查、Demo 用户、图片元数据和本地文件存储。
2. 再实现 Web 上传、时间线和删除流程。
3. 加入滤镜/美颜处理适配层，先用本地可替换实现，保留算法服务接口。
4. 实现好友/可见范围和消息互动。
5. 接入 AI 合照任务状态机与设备模拟面板。
6. 最后按联调验收文档补请求样例、测试证据和已知限制。

## 已验证的闭环

- 模板创作：上传图片后选择“窗台手账”模板，可叠加星星贴纸或日期戳；发布后元数据会随 Feed 返回。
- 轻信号图片消息：添加图片会先通过 `/v1/photos` 上传，再通过 `/v1/messages` 携带 `photo_id` 发送；会话中直接展示图片。
- 浏览器验收：桌面 1280px、移动 375px 均无横向溢出；模板和图片消息流程无控制台错误，相关请求返回 2xx/201。
- 好友请求：轻信号页支持输入 6 位 `friend_code` 发起请求，收件人可接受；设备状态会返回真实的待处理请求数。
- 设备上传限额：API 按“作者 + 设备 + UTC 日期”计数，默认每日 60 张，可由 `UPLOAD_DAILY_LIMIT` 调整；重复 `Idempotency-Key` 不重复计数，超限返回 `429` 和 `retry_after`。
- 照片访问安全：二进制下载需要认证并再次检查自己/好友可见性；Web 使用受保护图片加载器携带认证头，非法文案、尺寸和美颜参数返回 `400`。
- AI 适配边界：`AiProvider` 接口支持注入真实模型服务；Demo 默认使用命名为 `simulator` 的可重复 provider，成功/失败状态和 provider 名称都会返回给客户端。
- 图片存储边界：`PhotoStorage` 的 `save/read/remove` 接口支持注入 OSS 等对象存储；Demo 默认使用本地 `PhotoStore`，上传、鉴权下载和删除流程保持相同契约。
- 存储故障保护：文件保存失败返回 `503 STORAGE_UNAVAILABLE`，不会把未落盘照片写入 Feed；客户端可用原幂等键重试。
- 下载或删除存储失败同样返回 `503`；删除失败时保留元数据，避免对象仍存在但所有者失去管理入口。
- Web 发布错误边界：只有网络不可达时才使用本地 Demo fallback；API 的鉴权、限流、参数或存储错误会保留服务端错误并解除 busy 状态，避免把失败伪装成已发布。
- 会话隔离：`GET /v1/conversations/:id/messages` 只返回该会话双方的消息；无权或不存在的会话返回 `404`，不会泄露其他好友内容。
- 设备配对安全：配对码使用密码学随机的 6 位数字，并避免与当前未过期设备码重复；示例中的 `482913` 不会作为固定值返回。
