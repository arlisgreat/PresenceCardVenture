# MVP 需求

1 台 M5Stack CoreS3 Lite 展示设备，至少 200 位用户可扫码加入 Web 社区，无需硬件。

| 功能 | 要求 |
|------|------|
| 小卡 ↔ Web | 小卡拍照上传；Web 选图下发，小卡显示并回执 |
| 好友共创 | 原创 Dazz 类可选滤镜、image API 特效与 AI 合照；保留原图 |
| Web 社区 | 扫码加入、登录、加好友、文字与图片消息 |

- 社区邀请与设备绑定分开；下发须经设备主人授权。
- AI 合照须取得双方素材授权；支持内容删除。
- 本期不做语音、卡间离线互动及其联网补同步。
- 200 用户不等于 200 并发；并发场景与容量由全栈压测确认。

交付顺序见[联调验收](04-kickoff-playbook.md)，负责人见[分支与分工](05-team-roles.md)。
