# 算法

分支：`codex/algorithm`。目录：`server/effects/`、`docs/effects/`（待建）。

输入：吉吉的效果目标、全栈运行环境、硬件图像与性能约束。

| 交付 | 对接 |
|------|------|
| 原创 Dazz 类滤镜、参数、原图/结果对照 | 吉吉验视觉；硬件适配约定的端侧效果 |
| image API 与 AI 合照模块、运行说明、配置模板 | 全栈接入并部署 |
| 输入输出、状态/错误与超时约定 | 全栈确认后合入 `main` |
| 质量、延迟、成本及失败样例 | 吉吉验效果；全栈评估接入 |

验收：全栈可按说明独立调用滤镜与合照，获得结果或明确错误。
