# 算法

分支：`codex/algorithm`。代码：`server/effects/`；[接入说明](../effects/README.md)、[选型](../effects/research.md)、[验证](../effects/evaluation.md)。

输入：吉吉的效果目标、全栈运行环境、硬件图像与性能约束。

| 交付 | 对接 |
|------|------|
| Tiny：原创滤镜、色表、贴纸混合 | 硬件接帧缓冲；吉吉验视觉 |
| Live：随脸装饰、Web 跟踪与绘制 | 全栈接相机；吉吉给原创素材 |
| AI：双图合照、模型适配、配置 | 全栈接授权库、持久化及部署 |
| 对照样片、测试、延迟记录 | 吉吉验效果；真模型质量／费用另验 |

验收：全栈可按说明独立调用滤镜与合照，获得结果或明确错误。
