# 硬件

分支：`codex/hardware`。目录：`firmware/`。

输入：设备协议、全栈联调环境、xana 外观方案、吉吉屏稿与图标、算法效果参数。

| 交付 | 对接 |
|------|------|
| 拍照/JPEG 编码、Wi-Fi、上传、下载显示与回执 | 全栈联调 |
| 320×240 屏幕交互、约定滤镜的端侧适配及性能记录 | 吉吉验视觉；算法验效果 |
| 固件、烧录说明与串口日志 | 全栈复现 |
| 外壳建模、3D 打印与展示整机 | 按 xana 方案实现；吉吉提供效果图 |

验收：真机完成上传与下发闭环；断网重试不重复提交。端侧效果以实测为准。
