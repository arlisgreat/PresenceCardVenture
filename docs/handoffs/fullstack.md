# 全栈

分支：`codex/fullstack`。目录：`server/api/`、`server/web/`、`server/deploy/`。

输入：xana 的路演功能、吉吉的 UI 与图标、算法模块、`main` 设备协议。

| 交付 | 对接 |
|------|------|
| 扫码社区、好友、文字/图片消息、共创页面 | 吉吉验 UI；xana 确认路演功能 |
| 设备绑定、上传、下发与回执；联调地址及请求样例 | 硬件联调 |
| 图像模块接入、任务状态与失败处理 | 算法联调 |
| HTTPS、数据库、OSS、日志、备份、压测报告 | 全员获取环境与测试结果 |

验收：完成[联调用例](../04-kickoff-playbook.md)，无设备用户可参与，未授权用户不能下发。
