# 验证结果

日期：2026-08-27（洛杉矶）。这是实现与本机验证，不是公网、手机、小卡或真模型效果验收。

## 已验证

| 项目 | 结果 |
|---|---|
| Effects | 66 项测试通过；调色、图像校验、贴纸、LUT、Worker、模型适配器 |
| API | 72 项测试通过；授权、草稿隔离、取消／发布、设备图片、生产演示账号拦截；含编码路径／伪造图片字段回归 |
| Web | 原全栈 27 项测试与构建通过；未替换其页面 |
| 类型／构建 | API TypeScript、Prisma schema 校验通过；未连接真实数据库 |
| Tiny C/C++ | C99／C++11 编译通过；RGB565 全 65,536 色与 JS 查表一致 |
| Live 真模型 | 浏览器运行本地 MediaPipe：478 点、4 个贴纸绘制命令；初始化 508 ms，单帧 261 ms |
| Live 打包 | ESM Worker 独立构建通过；Vite 需 `worker.format='es'` |
| 命令行 | 样片渲染、LUT 导出、贴纸导出测试、模型资产下载、AI dry-run 通过 |

Live 仅用合成图片测试一次；没有打开相机、上传图片或调用云模型，不代表手机实时帧率。

## 调色与输出

[同源对比图](../../server/effects/examples/preview/comparison.png) · [原始测量](../../server/effects/examples/benchmark.json) · [样片来源](../../server/effects/examples/source-provenance.md)

Apple M2 / Node 24.19；每组顺序运行 10 次，计时包含解码、调色及 Web／小卡 JPEG 编码。

| 输入 | 原片 P50 | 4 款滤镜 P50 | 小卡输出 |
|---|---|---|---|
| 1448×1086 合成图 | 59 ms | 309–374 ms | 320×240，16,300–17,831 bytes |
| 同图缩为 320×240 | 12 ms | 23–25 ms | 320×240，14,528–15,476 bytes |

小样本 P95 等于本组最大值，见原始数据；不作为服务 SLA。缩图不是 GC0308 实拍，Mac 耗时不是 ESP32 性能。图像保留完整构图、补纸色边；JPEG 基线编码，限制 100 KiB。

滤镜为原创；样片由图像工具生成虚构人物，只验证调色链路，不证明双图合照或身份保持效果。

## 待验收

- 云模型：尚无项目密钥及两位所有者授权样本；未调用付费 API，不能给出实测身份保持率、合照质量、耗时或费用。
- 全栈：真实账号、可撤销授权、持久化队列／存储及公网部署；当前页面仍为原分支 Demo。
- 硬件：GC0308 原始帧、JPEG 软件编码／解码、RGB565 字节序、内存与帧率。
- 移动端：相机权限、跟踪稳定性、遮挡、镜像及退出清理。
- 部署镜像：本机无 Docker，未执行镜像构建；未改动阿里云服务。

云模型验收按[研究文档](research.md)固定样本与预算，比较原始模型结果及同强度后处理，先验身份与授权，再比较风格。
