# Presence

情侣/好友异步陪伴小相机 + 相框。相机端拍一张，相框端飘进来一张拍立得。

## 目录结构

```
presence-demo/
  frame-motion-demo.html   相框端动效演示 (800×480)，浏览器直接打开即可
```

## 相框端 demo 说明

`frame-motion-demo.html` 是纯前端单文件，零依赖，双击打开就能跑。

- 画布 800×480，对应相框屏幕分辨率
- 完整走一遍剧本循环：待机 → 照片到达（遮罩变暗 + 拍立得飘入）→ 停留展示 → 点赞星星爆发 → 淡出回待机
- 所有动效时序集中在 `TIMING` 常量里（脚本顶部），移植到 C++/嵌入式时照搬数值即可
- 颜色 token、缓动曲线来自《Presence小卡-屏幕UI与交互量化设计规范》§1 / §4
- 演示照片是 CSS 渐变生成的占位图（无外部资源），实机上替换为真实照片
